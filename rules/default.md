# 採用ルール（4人打ち半荘・ver.0.5 鳴きあり）
- プレイ人数: 4人打ち（東・南・西・北）
- 試合形式: 半荘戦（東1局〜南4局）。初期持ち点25,000点（30,000点返し / ウマ10-30 / 飛び終了あり）
- 使用牌: 136枚。赤ドラあり（0m, 0p, 0s 各1枚）
- 鳴き: チー（上家のみ）・ポン・大明槓・暗槓・加槓 有効。優先順位は「ロン ＞ ポン・大明槓 ＞ チー」。
- 喰いタン: あり / 喰い下がり: あり（三色同順・一気通貫・混全帯幺九・純全帯幺九・混一色・清一色は鳴くと1翻下がる）
- リーチ: 門前かつ聴牌（シャンテン数0）かつ持ち点1,000点以上・残り山4枚以上で宣言可能
- アガリ: 1翻縛り（ドラのみは不可）。フリテン時はロン不可（ツモのみ可）
- 牌表記: 1m..9m(萬), 1p..9p(筒), 1s..9s(索), 0m/0p/0s(赤5), 東/南/西/北/白/發/中

# 出力ルール（厳守）
- 必ず盤面レポート末尾の「実行可能な合法アクション一覧」に含まれる有効な行動のみを選択すること。
- チー（chi）の場合は `consume` 配列（手牌から出す2枚、例: `["2m", "3m"]`）も必ず指定すること。
- 思考（thought）には、点差・順位・他家リーチ・受け入れ枚数を踏まえた判断根拠を簡潔に書くこと。
- セリフ（talk）には、キャラクター口調で卓上に向けた短い一言（30文字以内）を書くこと。
