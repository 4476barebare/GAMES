# AI Mahjong Arena (4人麻雀 ver.0.3 - 鳴き＆個別APIキー＆スマホ最適化UI版)

## ver.0.3 の主なアップデート
- **鳴き（チー・ポン・大明槓・暗槓・加槓）完全実装**:
  - 他家打牌時の優先順位判定（ロン ＞ ポン・大明槓 ＞ チー）に対応。
  - カン時の嶺上牌ツモ・新ドラめくり・喰いタン・喰い下がり（三色/一気通貫/チャンタ/ジュンチャン）・門前限定役の自動除外・副露牌（鳴き面子）の表示エリアを実装。
- **座席ごとの個別モデル・APIキー・性格設定**:
  - 下家・対面・上家（AI観戦時は自席も）それぞれに個別の Gemini API キー・モデル・性格・作戦指示を設定可能。
- **内蔵AIの性格別ロジック実装**:
  - APIキー未入力時でも「デジタル派（受け入れ効率）」「超攻撃型（即リーチ＆鳴き速攻）」「オカルト・流れ重視派（ドラ＆染め手重視）」「鉄壁の守備派（他家リーチで現物ベタオリ）」で打ち筋が変化します。
- **スマホ縦画面レイアウト全面改修**:
  - 画面全体は `100dvh` 固定のまま、**自分の手牌エリアのみ横スクロール**できるようにし、端の牌やツモ牌も確実にタップ可能に改善。
  - チャットティッカー枠を廃止し、上家（左）を90°回転・下家（右）を270°回転表示にすることで、4家の河と副露（鳴き牌）置き場がすべて画面内に収まるよう調整。

## 導入手順
1. ZIPを展開し、各ファイル末尾の `.txt` を削除して本来の拡張子（`.html`, `.css`, `.js`, `.json`, `.md`, `.gs`）に戻します。
2. フォルダ構造を保ったまま `GAMES` リポジトリへ配置し、GitHub Pages で公開してください。
