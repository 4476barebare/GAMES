# AI Mahjong Arena (4人麻雀 ver.0.5 - 他家副露整列・卓全体スワイプ手牌スクロール・リーチ後オートツモ切り)

## ver.0.5 の主なアップデート
1. **4家すべての鳴き牌（副露）を各家の河の横に整列配置**:
   - 自分（Seat 0）：自河の右側
   - 対面（Seat 2）：対面河の左側（対面視点の右手側）
   - 上家（Seat 3）：上家河の下側（上家視点の右手側）
   - 下家（Seat 1）：下家河の上側（下家視点の右手側）
   - 左右回転ラベルとの重なりバグを解消し、4家の副露がすべて河の隣に綺麗に並ぶようにレイアウトを統一。
2. **卓全体での横スワイプ手牌スクロール**:
   - 卓ボード上のどこを横スワイプ（ドラッグ）しても手牌エリア（`#hand-scroll-wrap`）が連動して横スクロールするよう実装。
   - チー・ポン・カン・ロン等のアクションボタン上のタップ／操作判定は奪わないよう分離処理済み。
3. **リーチ後のオートツモ切り（ロン・ツモ和了可能時は自動停止）**:
   - リーチ宣言後、ツモ和了できる牌を引いた場合や、他家の捨て牌でロン和了できる場合は自動で止まりボタンを表示。
   - 和了できない巡目は約0.45秒の視認ウェイト後に自動でツモ切りを実行。

## 導入手順
1. ZIPを展開し、各ファイル末尾の `.txt` を削除して本来の拡張子（`.html`, `.css`, `.js`, `.json`, `.md`, `.gs`）に戻します。
2. フォルダ構造を保ったまま `GAMES` リポジトリへ配置し、GitHub Pages で公開してください。

## SVG牌セット対応
- `js/tileSvg.js`（全38種SVG牌モジュール）を追加し、`js/ui.js` および `css/style.css` をSVG牌描画に差し替え済みです。

## ver.0.6 UIブラッシュアップ
- 相手の牌公開切替ボタンを削除
- 自家ツモ時に毎回手牌スクロールを右端（ツモ牌側）へ自動リセット
- 上家の副露牌を270度回転・縦並び（上家側向き）、下家の副露牌を90度回転・縦並び（下家側向き）に変更
- 鳴き（チー・ポン・カン）・立直・和了ボタン内の牌表記をSVGアイコン化
- 対戦相手名から「対・」「上・」「下・」の省略プレフィックスを廃止し、フルネーム表示枠を拡張

## ver.0.8 GASオンライン対人戦（A案・4人ハイブリッド卓）
- **GASエンドポイント直書き済み**: `js/sync.js` にデプロイ済みWebアプリURLを設定済み。
- **ハイブリッド4人卓＆席順ランダム化**: 待機室に人間1〜4人が着席し、開始時に4席（東・南・西・北）をランダムシャッフル＆空き席をホスト設定のAIで自動補充。
- **公開ロビー＆招待URL両対応**: 公開ルーム一覧からの参加と、4桁番号・`?room=XXXX` 招待URLからの直接入室に対応。リロードしても自席へ自動復帰。
- **相対視点描画**: どの席（Seat 0〜3）に着席しても、各プレイヤーの画面では常に「自席が手前・下家が右・対面が上・上家が左」に自動回転して表示。
- **次局全員OK＆ホストのキック機能**: 局終了後は全人間プレイヤーが「OK」を押すと次局へ進行。ホストは誤タップ防止の確認ダイアログ付きで他プレイヤーをキック可能（対局中は即座に内蔵AI代行へ切替）。
- **リロード連打・GAS無料枠保護**: ブラウザ側キャッシュ＆連続取得クールダウン＋タブ非表示時のポーリング自動停止を実装。
