# AI Mahjong Arena (4人麻雀 ver.0.2)

BYOK（ユーザー持ち込みAPIキー）型の4人打ちマルチAI麻雀アリーナ。
将来の鳴き（チー・ポン・カン）実装および GAS オンライン対戦ロビー接続を前提に、土台となる4人卓UI・自動保存・半荘精算を完成させたバージョンです。

## ver.0.2 の主なアップデート
- **4人麻雀専用化**: 東・南・西・北の4席構成（人間 vs AI 3人 / AI 4人オート観戦）。
- **1画面固定UI（スクロールゼロ）**: `100dvh` 固定の雀卓レイアウト（上：対面、左：上家、右：下家、下：自分、中央：4家の河とドラ・局情報）。打牌しても画面が一切スクロールしません。
- **リロード自動保存・自動復帰**: 1打ごとに `localStorage` へ `gameState` と対局ログを自動保存。誤ってブラウザをリロードしても直前の手番からそのまま再開できます。
- **半荘（東1〜南4局）進行と最終精算**: 連荘・本場・飛び終了（0点未満）・複数ロン対応・最終順位とウマ(10-30)/オカ(+20)の精算モーダルを実装。

## 導入手順（GitHub Pages）
1. ZIPを展開し、各ファイル末尾の `.txt` を削除して本来の拡張子（`.html`, `.css`, `.js`, `.json`, `.md`, `.gs`）に戻します。
2. フォルダ構造を保ったまま `GAMES` リポジトリへ配置し、GitHub Pages で公開してください。
