# AI Mahjong Arena (4人麻雀 ver.0.5 - 他家副露整列・卓全体スワイプ手牌スクロール・リーチ後オートツモ切り)

## ver.0.5 の主なアップデート
1. **4家すべての鳴き牌（副露）を各家の河の横に整列配置**:
   - 自分（Seat 0）：自河の右側
   - 対面（Seat 2）：対面河の左側（対面視点の右手側）
   - 上家（Seat 3）：上家河の下側（上家視点の右手側）
   - 下家（Seat 1）：下家河の上側（下家視点の右手側）
   - 左右回転ラベルとの重なりバグを解消し、4家の副露がすべて河の隣に綺麗に並ぶようにレイアウトを統一。
2. **卓全体での横スワイプ手牌スクロール**:
   - 卓ボード上のどこを横スワイプ（ドラッグ）しても手牌エリア（`#hand-scroll-wrap`）が連動して横スクロールするよう実装。
   - チー・ポン・カン・ロン等のアクションボタン上のタップ／操作判定は奪わないよう分離処理済み。
3. **リーチ後のオートツモ切り（ロン・ツモ和了可能時は自動停止）**:
   - リーチ宣言後、ツモ和了できる牌を引いた場合や、他家の捨て牌でロン和了できる場合は自動で止まりボタンを表示。
   - 和了できない巡目は約0.45秒の視認ウェイト後に自動でツモ切りを実行。

## 導入手順
1. ZIPを展開し、各ファイル末尾の `.txt` を削除して本来の拡張子（`.html`, `.css`, `.js`, `.json`, `.md`, `.gs`）に戻します。
2. フォルダ構造を保ったまま `GAMES` リポジトリへ配置し、GitHub Pages で公開してください。

## SVG牌セット対応
- `js/tileSvg.js`（全38種SVG牌モジュール）を追加し、`js/ui.js` および `css/style.css` をSVG牌描画に差し替え済みです。

## ver.0.6 UIブラッシュアップ
- 相手の牌公開切替ボタンを削除
- 自家ツモ時に毎回手牌スクロールを右端（ツモ牌側）へ自動リセット
- 上家の副露牌を270度回転・縦並び（上家側向き）、下家の副露牌を90度回転・縦並び（下家側向き）に変更
- 鳴き（チー・ポン・カン）・立直・和了ボタン内の牌表記をSVGアイコン化
- 対戦相手名から「対・」「上・」「下・」の省略プレフィックスを廃止し、フルネーム表示枠を拡張

## ver.0.7 土台仕上げ（セキュリティ・ルール・パフォーマンス改修）
- **共通APIキー廃止・座席別個別設定のみへ統一**: `globalApiKey` および共通キー入力欄を削除し、各席の個別APIキー・モデル・性格設定のみで運用する構成に変更。
- **APIキーの `gameState` 完全分離（GAS拡張対策）**: `gameState.players[].aiConfig` に `apiKey` を一切格納せず、API通信時のみ `storage.js`（`localStorage`）から直接参照する仕様へ修正。旧セッション復帰時の自動浄化にも対応。
- **APIトークン／クォータ切れ時の自動簡易AI切替**: 対局中にHTTP `429`/`402`/`401`/`403` やクォータ超過エラーが発生した場合、その半荘の該当席のみ自動で内蔵簡易AIへ切り替えて完走させるよう実装（設定自体は保持され、次の新規半荘では元設定が有効）。
- **カン複数回時の王牌インデックスズレ修正**: 王牌14枚を `rinshanTiles`（4枚）・`doraPool`（5枚）・`uraDoraPool`（5枚）に分離管理し、4回カンしても表ドラ・裏ドラの位置がズレないよう修正。
- **鳴きルール補強（赤5チー選択＋喰い替え禁止）**: 手牌に通常5と赤5の両方がある場合にチーの消費牌として両方を選択可能にし、ポン・チー直後の現物喰い替えおよびスジ喰い替えを禁止（禁止牌は手牌上でグレーアウト＆選択不可）。
- **描画パフォーマンス最適化**: 2段階タップ打牌の1回目タップ時はDOM全再描画を廃止してハイライトのみ即時更新。さらに4家の河・副露・ドラ表示牌・手牌・思考カード・シャンテン計算へ差分描画ガードを導入。
