# AI Mahjong Arena (4人麻雀 ver.0.4 - 卓UI・2段階打牌・鳴きスルー操作改善版)

## ver.0.4 の主なアップデート
1. **自分のツモ牌＆最新の相手捨て牌の黄色枠ハイライト**:
   - ツモ牌と直前に他家が切った最新の捨て牌に、視認性の高い黄色枠（`.highlight-yellow`）を常時付与。
2. **誤タップ防止の2段階打牌（選択 → 確定）**:
   - 自分の打牌フェーズで1回タップするとその牌に黄色い選択枠が移動し、もう一度同じ牌をタップすると打牌確定。リーチボタンも選択中の牌、またはリーチ可能な候補から直接実行可能。
3. **鳴き・ロン判定時の全選択肢表示＆手牌タップでスルー**:
   - 鳴き判定中はアクションバーから自分の「南 あなた 31,200」表示と「スルー」ボタンを非表示にし、チー（複数パターン）・ポン・カン・ロンの全ボタンを横並び表示。
   - 鳴き判定中は自分の手牌全体に黄色い枠が付き、手牌のどこかをタップすることで「スルー（見送り）」を実行。
4. **鳴き牌（副露）の配置変更**:
   - 自分の鳴き牌は手牌の右横ではなく、**自分の河（river-0）の右側**へ配置し、手牌の横幅をフル確保。
5. **ヘッダーの横スクロール復活**:
   - 狭いスマホ画面でもトップバーのボタンが右端で見切れず横スクロールできるよう修正。

## 導入手順
1. ZIPを展開し、各ファイル末尾の `.txt` を削除して本来の拡張子（`.html`, `.css`, `.js`, `.json`, `.md`, `.gs`）に戻します。
2. フォルダ構造を保ったまま `GAMES` リポジトリへ配置し、GitHub Pages で公開してください。
